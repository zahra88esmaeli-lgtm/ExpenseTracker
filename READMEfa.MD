# ExpenseTracker

A simple console expense manager built with C# and .NET 10.
مدیریت ساده هزینه‌ها به‌صورت برنامه کنسولی با C# و .NET 10.

## Features | قابلیت‌ها
- Add and remove expenses | افزودن و حذف هزینه
- View all expenses | نمایش همه هزینه‌ها
- Total of all expenses | جمع کل هزینه‌ها
- Totals by category | جمع هزینه‌ها به تفکیک دسته
- Data saved in a JSON file | ذخیره داده‌ها در فایل JSON

## Technologies | فناوری‌ها
- C#, .NET 10
- System.Text.Json
- Interface + service class (separation of concerns)

## How to run | نحوه اجرا
1. Install the .NET 10 SDK
2. Clone the repo: `git clone <https://github.com/zahra88esmaeli-lgtm/TDoApp.git>`
3. Open the folder and run: `dotnet run`
