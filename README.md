# ExpenseTracker

A simple console expense manager built with C# and .NET 10.

## Features
- Add and remove expenses
- View all expenses
- View the total of all expenses
- View totals by category
- Data is saved automatically to a JSON file

## Technologies
- C#, .NET 10
- System.Text.Json
- Interface + service class (separation of concerns)

## How to Run
1. Install the [.NET 10 SDK](https://dotnet.microsoft.com/download)
2. Clone the repository:
   `git clone <https://github.com/zahra88esmaeli-lgtm/TDoApp.git>`
3. Open the project folder and run:
   `dotnet run`

## Menu
1. Add Expense
2. View All Expenses
3. View Total Expenses
4. Remove Expense
5. View Totals by Category
6. Exit
